# 🌌 Galactic-Voyages
Explore black holes in intergalactic voids. Navigate by galaxy, cluster, or cosmic filament.

## 🚀 Overview
Galactic-Voyages is a cosmic exploration app that lets users traverse the universe in search of black holes—those mysterious, gravity-warping titans that bend space and time. Whether you're a curious student or a seasoned astrophysicist, this app offers a layered experience: stunning visuals, interactive simulations, and rich scientific data, all wrapped in a fun, geeky interface.

## 🧭 Key Features
🕳️ Black Hole Atlas Navigate a dynamic map of the observable universe, locating black holes by galaxy, cluster, or filament. Each entry includes:

Fun name (e.g., Voidzilla, Spaghettifier Prime)

Scientific designation (e.g., TON 618, M87*)

Location coordinates and cosmic neighborhood

## 📊 Influence Index Compare black holes by:

Mass (solar mass equivalents)

Accretion disk activity

Gravitational influence radius

Time dilation effects

## 🎨 Visual Playground

Artistic renderings of gravitational lensing

Animated accretion spirals

Interactive simulations of tidal forces and spaghettification

## 🔍 Deep Dive Modules

Singularity Scanner: Explore core properties like spin, charge, and entropy

Void Voyages: Discover black holes in low-density regions

Quasar Quest: Track active galactic nuclei and their monstrous cores

## 🧑‍🏫 Audience
Designed for:

Serious elementary school students: Visual-first, gamified exploration with simplified explanations

Middle and high schoolers: Layered data, glossary terms, and guided missions

University students and PhDs: Full access to scientific datasets, simulation parameters, and research-grade visualizations
